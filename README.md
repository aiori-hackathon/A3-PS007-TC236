## Run the demo
1. Download `index.html`.
2. Double-click it to open in a modern browser. No installation or internet connection is required.
3. Click **Simulate address rotation** to create a high-risk heuristic signal.
4. Point out that summaries show a pseudonymous device label and a redacted IPv6 address.
5. Explain that alerts are signals for human review, not proof of an attack.

## Important scope note
This is a local front-end demonstration using synthetic data and client-side heuristics. It does not connect to real IoT devices, a FastAPI service, or persistent storage, and it is not a deployed live service. Do not describe it as a production or live backend. For the AIORI submission, use this as a demo artifact only if it accurately represents the team's current implementation; otherwise upload and demonstrate the actual backend project.
